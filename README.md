# Retail Demand Forecasting & Sales Prediction System

## Project Overview
A machine learning project to analyze historical retail sales and predict future sales using time-series features and regression models.

## Project Workflow
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Model Training and MLflow Experiment Tracking
5. Model Evaluation and Reporting

## Repository Structure
- `data/cleaned/`: Cleaned datasets
- `notebooks/`: Jupyter notebooks
- `src/`: Reusable Python code
- `models/`: Trained models
- `reports/`: Analysis and evaluation reports

## Dataset
The cleaned datasets and data-cleaning documentation will be provided in `data/cleaned/` and `data/notes_data.md`.
